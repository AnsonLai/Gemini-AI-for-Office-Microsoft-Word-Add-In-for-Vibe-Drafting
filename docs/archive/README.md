# Archive

These files are historical and unmaintained. They are kept for reference only
and may describe things that no longer exist (the in-repo engine, the browser
demo, the MCP server, retired tools and old library pins).

- `migrated-plans/` holds superseded plans whose open work was consolidated into later dated plans.
- The other files are earlier root-level and `docs/` documents (old plans, the session summary log, the old specification).

Current state lives in [STATE.md](../../STATE.md), [ROADMAP.md](../../ROADMAP.md) and [docs/plans/](../plans/).
