## What changed

- **Comment merge.** `consumer-core.js` merges comment parts with the library's `mergeCommentParts` (new in 0.11.0) instead of wrapping them in `MemoryZip` and calling `reconcileCommentSiblingParts`. The library refuses a commentsExtended merge delta on a package with thread metadata (`UNSUPPORTED_EXISTING_COMMENT_THREAD_METADATA`); the plugin passes the code through. Relationships are still ensured for every changed or added comment part.
- **Imports.** `src/` now imports only the library root and the documented `/standalone-runner` subpath. Earlier WP1 steps removed the `xml-adapter`, `package-builder` and `package-parts` deep imports.
- **Size.** Production lines 4,363 (WP2 end) → 4,297.

## Tried and reverted

Plain-text insertions (`structuredContent: false` for `insert_paragraph`, `append_paragraph`, `insert_list_item`, without list-marker synthesis) passed offline and Office.js. The Word oracle then failed `direct-basic-underline-format` twice (Reject All 55 vs 56 paragraphs): a library 0.11.0 defect tracks the new paragraph's mark on an "after" insertion, which at body end is the final paragraph mark (KB-9). Reverted in `c82c190`; reported to the library with a reproducer.
