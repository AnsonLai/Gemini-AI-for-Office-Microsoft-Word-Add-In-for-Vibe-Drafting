# Release v2.3.0.0

Releases are reflected in the commercially available version on the Microsoft Marketplace at:
https://marketplace.microsoft.com/en-ca/product/saas/wa200009707

## Key Changes

**Updated docx-redline-js:** Gemini AI for Office now uses `@ansonlai/docx-redline-js` version `0.11.0` (from `0.8.4`), and the shared library does all document editing.

**Verified edits:** Every edit is prepared as one batch, written to Word in a single step, and then checked against what Word actually saved: the text, list labels, tables, tracked changes and comments. If the check fails, the assistant tells you to look at the document instead of reporting success, and it never silently retries an edit.

**Safer recovery:** Before each edit the add-in saves the exact state it is about to change, and the edit doesn't run if that save fails. **Revert** restores that state and checks that the restore worked.

**Turning headings into a real list:** Requests such as "turn all the headers into a proper ordered list" now work. Typed numbers or letters ("1.", "A.", "iv.") become real list numbering as a tracked change; Reject All brings the typed numbers back.

**Changing list numbering:** A list can switch format, for example from bullets to 1, 2, 3 or from numbers to A, B, C, and a later list can continue the numbering of an earlier one.

**Edits inside other reviewers' changes:** Editing a paragraph that holds another reviewer's pending changes keeps their changes and their name, so Accept All and Reject All still work for both reviewers. Your own earlier pending changes in the paragraph are merged rather than stacked.

**Signature and date lines:** Underscore lines such as "Signed: ____________" keep every underscore when a paragraph or table is edited, and text you ask for is written literally rather than read as formatting.

**Comments and threads:** Adding comments keeps existing comments, replies and resolved threads intact, including documents with Word's newer threaded comments.

**Your tracked-change author everywhere:** All edits now go through the shared library, so every tracked change uses the redline author set in the add-in. Word's own editing commands, which recorded some changes under the Office user name, are no longer used.

**Choose any Gemini model:** In Settings, each of the Fast and Slow models can be set to a custom model ID from Google AI Studio, which helps when a preset model is busy or unavailable for your API key.

**Safer chat display:** Chat replies are sanitized before they are shown, and a content security policy limits the task pane to the add-in's own files, Office's script library, Google Fonts, and connections to Google's Gemini API.

**Smaller and faster:** The add-in's own document-handling code is about half its previous size. Editing support loads only when first needed.

**Expanded quality checks:** Every change is checked against real Microsoft Word: Office.js validation of 20 editing cases, an independent check of Accept All and Reject All in desktop Word, and a 16-request editing session on a sample NDA.

**Shared redline engine:** The document reconciliation engine continues to live in its own reusable package:
[https://github.com/AnsonLai/docx-redline-js](https://github.com/AnsonLai/docx-redline-js)

## No Longer Supported

To keep every edit verifiable, the assistant now refuses these requests and leaves the document unchanged, explaining why. Make these changes in Word directly:

- Creating a table from paragraphs, or adding, removing or reshaping table rows and columns.
- Inserting list items deeper than the second level, or changing a list item's level or indentation.
- Restructuring one provision into an introduction plus bullets, or splitting a list into ranges.
- Inserting a plain paragraph inside a table, or beside a heading or list item (ask to add a list item instead).
- Font family, font size, page layout, accepting or rejecting tracked changes, and anything outside the document text.

Text edits, comments, highlighting, bold/italic/underline/strikethrough, paragraph insertion and deletion, list item insertion at the first two levels, and the list changes above remain supported.

## Known Issues

**Word Online:** Word Online has not been re-checked for this release and may still be slow and unreliable when running many commands or a long task.
