# Release v2.4.0.0

Releases are reflected in the commercially available version on the Microsoft Marketplace at:
https://marketplace.microsoft.com/en-ca/product/saas/wa200009707

This release adds web search and two Gemini 4 models, makes Revert, Cancel and Settings behave more predictably, and lets the assistant create new bulleted and numbered lists. It uses the same `@ansonlai/docx-redline-js` version, `0.11.1`.

## Key Changes

**Web search:** The assistant can now look up current or outside facts, such as a law, citation, date, address or company name, using Google search through your Gemini key. It says which facts came from the web and names the source, and it treats web results as reference material, never as instructions.

**New Gemini 4 models:** Gemini 4 Carbon and Gemini 4 Argon can now be chosen in Settings for both the Fast and Slow models. Gemini 4 Carbon is the new default Slow model, replacing Gemini 2.5 Pro. If you have already chosen a Slow model, your choice is unchanged.

**New bullets and numbered items:** A request such as "rewrite this clause as an opening paragraph followed by a few bullets" is now carried out, with the items as a real list in Word. Before, the assistant refused, did only the rewrite, or left plain paragraphs in place of the list. When one paragraph is to become several, the assistant rewrites it as the first of them and adds the rest after it.

**Glance runs only when you ask:** The Glance checks no longer run automatically when the pane opens. Press refresh on the Glance panel to run them, or turn on "Run Glance checks when the pane opens" in Settings. Each check sends the full document text to Gemini, and Glance now declines documents over 30,000 words.

**Revert asks before undoing later changes:** If the document changed after an edit, including your own typing or a later edit, Revert now says so and asks you to choose "Revert anyway" or "Keep document". Before, it restored the earlier state without warning. Revert is refused while a request is running, instead of stopping that request.

**Revert works on documents with tables:** Revert restored a document with tables correctly but then reported that the result "could not be verified". It now verifies correctly, including tables inside footnotes, endnotes and comments.

**Cancel and refresh behave predictably:** The Cancel button stays visible while the assistant works through its steps. Cancelling while the document is being read shows "Request cancelled." instead of an error. Refresh waits up to 15 seconds for a cancelled request to finish before clearing the chat; if Word is still working, it says so and leaves the chat as it is. If the cancelled request's edit still reached the document, the fresh chat carries a note with a Revert button.

**Failures after an edit end safely:** If something fails after the assistant has edited or tried to edit, it stops, reports what was done, asks you to inspect the document, and offers no Retry that could repeat the edit. If the failure follows only reading or refused edits, nothing was changed and Retry puts your question back in the message box. Whenever the assistant has to forget the conversation, its message says so.

**Settings save as you change them:** The Save button is gone. Each setting saves when you change it and shows "Saved." An invalid custom model ID shows an error and is not saved. Clearing the API key now removes the stored key. Settings messages appear inside Settings instead of in the hidden chat.

**Smaller fixes:** An API key pasted with stray spaces or invisible characters is reported with a message to paste it again. Dropping text onto a Glance question no longer moves the last question. Each open task pane keeps its own ten most recent Revert points.

**Expanded quality checks:** A new automated lane runs the task pane's Revert, Cancel, Retry and Settings checks in real Word (14 pass, 2 skipped by design). The 16-request NDA session passed in real Word with scripted responses and live with Gemini Flash (53 checks each), and the 16-request privacy notice session passed live with Gemini Flash (65 checks). The first 11 NDA requests also passed live with Gemini 4 Carbon (35 checks); Gemini 4 Carbon was not run through all 16.

## Now Supported

Restructuring one provision into an introduction plus bullets, listed as not supported in v2.3.0.0, now works (see "New bullets and numbered items").

## Known Issues

**"Revert anyway" discards later changes:** If you choose "Revert anyway", everything done since the edit, including your own typing, is discarded, and the add-in cannot bring it back. Choose "Keep document" unless you are sure.

**Deleting a paragraph after new paragraphs were added below it:** With track changes on, if the assistant has just added new paragraphs below a paragraph, a request to delete that paragraph can be refused. Accept the additions and ask again, or delete the paragraph yourself in Word. A fix is planned in the shared library.

**Bold lost after a later wording change:** With track changes on, if you bold words and then ask for a wording change elsewhere in the same paragraph before accepting the bold, the bold can be lost. Accept the formatting change first, or reapply the bold after the wording change. A fix is planned in the shared library.

**Gemini 4 Carbon can be slow:** In testing, single requests with Gemini 4 Carbon often took one to four minutes, and some were retried automatically after the provider timed out. A long request can reach the five-minute limit; any edits already made stay in the document and can be reverted. Choose a faster Slow model in Settings if this affects you.

**Word Online:** Word Online has not been re-checked for this release and may still be slow and unreliable when running many commands or a long task.

**Clarifying questions:** With some models, the assistant occasionally asks a question instead of acting. Answer or rephrase the request to continue.

**Long requests:** A request that needs many steps can reach the assistant's turn limit. If that happens right after an edit, the reply reports the edit but may not include the assistant's usual summary; the edit stays in the document.
