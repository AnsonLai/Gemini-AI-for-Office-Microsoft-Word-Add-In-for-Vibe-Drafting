# Release v2.2.0.0

Releases are reflected in the commercially available version on the Microsoft Marketplace at:
https://marketplace.microsoft.com/en-ca/product/saas/wa200009707

## Key Changes

**Updated docx-redline-js:** Gemini AI for Office now uses `@ansonlai/docx-redline-js` version `0.8.3`, keeping the Word add-in aligned with the shared DOCX redline engine.

**More faithful tracked changes:** Paragraph insertion and list-range replacement now reject cleanly, preserving the original paragraph boundaries, empty list items, and list numbering. Hyperlink punctuation and manual line breaks also retain their original placement when changes are accepted or rejected.

**More reliable editing tools:** List and table commands validate their targets and inputs before editing. Supported redline batches check their source document context and refuse stale targets, while clearer operation results distinguish successful edits from failures or uncertain Word writes.

**Faster startup:** Editing support loads when first needed, reducing the add-in's initial JavaScript payload.

**Expanded quality checks:** Automated regression coverage now includes real Microsoft Word and Office.js validation of tracked changes, list numbering, formatting preservation, and Accept All/Reject All behavior.

**Shared redline engine:** The document reconciliation engine continues to live in its own reusable package:
[https://github.com/AnsonLai/docx-redline-js](https://github.com/AnsonLai/docx-redline-js)

## Known Issues

**Word Online:** Word Online continues to be slow and unreliable when running many commands or a long task.
