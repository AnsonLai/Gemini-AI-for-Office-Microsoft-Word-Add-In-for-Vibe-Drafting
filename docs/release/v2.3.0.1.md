# Release v2.3.0.1

Releases are reflected in the commercially available version on the Microsoft Marketplace at:
https://marketplace.microsoft.com/en-ca/product/saas/wa200009707

A patch release for problems found in everyday use of v2.3.0.0. It uses the same `@ansonlai/docx-redline-js` version, `0.11.1`.

## Key Changes

**Several paragraphs at once:** When the assistant adds text that should be more than one paragraph, each paragraph is now its own paragraph in Word: a poem, an address, recitals, a heading with its body text, or several new list items. Before, the lines were run together into one paragraph or joined with slashes.

**Formatting several words in a paragraph:** Requests such as "bold the all-caps words" or "bold every *your*" now work in one step, even when the words are in the same paragraph. Before, they were refused.

**Several changes to one paragraph:** Changing two words in the same paragraph, changing each repeat of a word, adding text both before and after a paragraph, or adding several comments to one paragraph now happens in one step instead of being refused.

**Adding text next to a heading:** When asked to add text just before or under a heading, the assistant now places it using the neighbouring paragraph instead of giving up. A heading itself still can't be the paragraph that new text is attached to, because the new text would take on the heading's style.

**Better use of the editing tools:** The assistant now uses a small, exact replacement for small wording changes and a full rewrite only for broad revisions. It follows each refusal's suggested next step, and the add-in no longer sends an edit again in the same request after it has been refused.

**Expanded quality checks:** The sample privacy notice session grows from 10 to 16 requests covering the changes above. It passes in real Word with scripted responses and was run with a live Gemini model, alongside the 16-request NDA session.

## Known Issues

**Bold lost after a later wording change:** With track changes on, if you bold words and then ask for a wording change elsewhere in the same paragraph before accepting the bold, the bold can be lost. Accept the formatting change first, or reapply the bold after the wording change. A fix is planned in the shared library.

**Word Online:** Word Online has not been re-checked for this release and may still be slow and unreliable when running many commands or a long task.

**Clarifying questions:** With some models, the assistant occasionally asks a question instead of acting. Answer or rephrase the request to continue.

**Long requests:** A request that needs many steps can reach the assistant's turn limit. If that happens right after an edit, the reply reports the edit but may not include the assistant's usual summary; the edit stays in the document.
